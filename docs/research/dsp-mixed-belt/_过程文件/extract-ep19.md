## 第1部分 (00:00-17:53)

### A. 前置/工厂背景
- 产线里所有有两种或更多进料的物品，全部用混带生产；此混带与之前的「混带超市」有很大区别 [BV1fXkxYDEbW 00:14]
- 黄剂、金刚石都是单进单出，没有混带科技，按「一屋一塔」做 [BV1fXkxYDEbW 03:44]；黄剂+金刚石→绿剂是两进一出，才上混带 [BV1fXkxYDEbW 04:01]
- 混带不能「无脑拉几条线」；每个物品制造时间、进料比例都不同，每个混带要专门设计，「费脑子」，但「为了节省CPU是值得的」 [BV1fXkxYDEbW 04:16]

### B. 机器数/带子容量算法 (推导)
- 例：绿剂配方1秒耗3个物品出1个；增产剂选加速=2倍制造速度，黑物重组制造台自带3倍，乘算=6倍 [BV1fXkxYDEbW 04:35]
- 因此一台绿剂机每秒耗 18 个物品 (3×6) [BV1fXkxYDEbW 04:54]
- 四叠蓝带流速7200/分钟 ÷60 = 120 个/秒 [BV1fXkxYDEbW 05:00]
- 120/18=6.66，一条蓝带带6台，「带7个是不可以的」：第七台会有1/3时间不工作，机器多了会「开始卡」 [BV1fXkxYDEbW 05:07]
- 做每条混带的两件事：(1) 算一条蓝带能带多少台机器；(2) 关注投料比例，本例 金刚石:黄剂=1:2 [BV1fXkxYDEbW 05:25]

### C. 旧方案(梯口/「剃口」，黑物超市版)的缺陷
- 结构：大环带放所有物品；白爪回收金刚石；金刚石由一条绿带投料（绿带可用爪子或带子） [BV1fXkxYDEbW 05:49]
- 绿带运力=蓝带的 2/5；需要金刚石 1/3 带，却投了 2/5 (因为 1/3 要用爪子，不好算) [BV1fXkxYDEbW 06:01]
- 黄剂投料=一条绿带(12/s) + 一个蓝爪(6/s)，合计 3/5 蓝带 (ASR?：数字似为未叠加基础值，×4叠加后=72/s=3/5×120) [BV1fXkxYDEbW 06:28]

### E. 核心投料结构（两种货物，分离+定量补料）
- 结构：大环带(同普通混带环带)；黄剂由一条蓝带「直接怼」到环带上；金刚石通过绿带怼到环带上；这一处共两格绿带，其余全蓝带；末端一个白爪(筛选黄剂)把黄剂从一格抓到前面一格；白爪需「跑到白爪无限运力」的科技 [BV1fXkxYDEbW 10:40]
- 关键两件：跨格的白爪 + 那一格绿带 [BV1fXkxYDEbW 11:42]
- 白爪作用：黄剂一到该格就被传送到前面格，永远不进中间三格带子 → 中间三格只有金刚石；类似「四向分流器筛选」把两种货物分开，之后可分别补到想要的流量 [BV1fXkxYDEbW 11:51]
- 黄剂被拉走后，绿带那格只经过上一圈回流的金刚石；回流金刚石与带上金刚石的汇合是「转弯让直行」(ASR?原则)：回流金刚石优先，再被带上金刚石补上 [BV1fXkxYDEbW 12:16]
- 二者之和不能超过绿带运力，故下游蓝带格上金刚石精确=2/5（只要回流不超过2/5），与回流多少无关 [BV1fXkxYDEbW 12:33]
- 白爪把回流黄剂也放到这一格；随后黄剂直接怼上去，只能占剩余流量 → 黄剂精确=3/5（金刚石占2/5之后，捕获黄剂只占剩余） [BV1fXkxYDEbW 13:00]
- 验证：流速监测器在该点精准7200(满)；探测口若再往前提，可测到精准7200 [BV1fXkxYDEbW 13:31]
- 总结：先分离两货物 → 金刚石补到精准2/5 → 黄剂占剩下3/5；两货物都满时，不管回流多少，出口恒为2/5:3/5 [BV1fXkxYDEbW 13:49]

### F. 断货与防堵、重启
- 黄剂断货：带上黄剂耗尽稳定后每格仍有空位，不堵；关键是那格绿带，限定环带上金刚石流量≤一格绿带；两格绿带实际堵满=金刚石补不进去，故金刚石流量恒为绿带(2/5)；黄剂恢复即继续生产 [BV1fXkxYDEbW 14:41]
- 金刚石断货：黄剂由蓝带直接怼，会以蓝带流量把整个环带黄剂占满，但「没关系」：黄剂到该格就被传送到前方格，中间三格上没有黄剂 → 金刚石接上仍能输入；重启「没有另一方向断货那么快」但足够快 [BV1fXkxYDEbW 15:55]
- 总之：用绿带(限流)补的货物不会占满环带；直接蓝带怼上的货物会占满，但传送爪保证另一种货物仍有入口 [BV1fXkxYDEbW 16:35]
- 为什么那一格必须是绿带而不是蓝带（演示：金刚石断、黄剂堵满环带后，把那格改蓝带再接金刚石）：金刚石「可能进一两个」后进不去；带上移动的物品只是动画，逻辑层没动 [BV1fXkxYDEbW 17:13]
- 原因：当该格是蓝带，环上黄剂以蓝带速率(7200/分钟)移动，白爪优先级高于直行带，白爪也以7200搬运黄剂，把该格占满，金刚石无缝插入 [BV1fXkxYDEbW 17:34] (后续在下一部分延续)

## 第2部分 (17:54-37:13)

### G. 为什么「限流格」必须是绿带（机理）
- 若该格是蓝带：白爪以7200/分钟把黄剂放到该格，占满蓝带，金刚石永远过不去 → 堵货 [BV1fXkxYDEbW 17:54]
- 该格为绿带：环上黄剂要过绿带 → 整条大环带黄剂流量被降到绿带流量；白爪运力「匹配这个流速」，故每单位时间出现在该蓝带格的黄剂只有一个绿带流量，剩余 3/5 流量留给金刚石 [BV1fXkxYDEbW 18:26]
- 金刚石接上后一开始进得不多，但机器复工后黄剂按正常速率被消耗，一段时间后金刚石流量恢复正常 [BV1fXkxYDEbW 19:41]
- 整个系统依赖这一个「捕获口」；一个捕获口只用一个爪子，其余都是直接用传送带怼上去 [BV1fXkxYDEbW 20:46]

### L. 通用设计规则（如何选补料位置）——核心推导
- 不管两种货物消耗差异，每经过一台机器都流出 4.5叠/s 空余(=每台总消耗)；补满后空余为0 [BV1fXkxYDEbW 30:55]
- 过 n 台后补一种货物，补上的量=这 n 台的总消耗量(=n×4.5叠/s)：过2台补金刚石补 9叠/s；过4台补黄剂补 18叠/s [BV1fXkxYDEbW 31:14]
