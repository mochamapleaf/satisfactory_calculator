# Critic review：`00-最终报告.md`（DSP 种子 → 全星区规划）

审稿日期 2026-11-21 · 对抗式审稿（核查引用、复算数字、检查推理）。本文件只给作者用，不交给 Xinyu。

## 总评

核心数字都对：许可证、S(L) 表、815448、3716k、样例总量、规划器情形 A/E/F/G、磁石阈值 L98 全部复算一致。
主要问题在推理和框架：
1. §0.3 和 §5.3 说“终局最大白糖无界”，这与报告自己列出的硬上限矛盾。
2. §4 的“足以无限研究”只在白糖全部投入矿物利用时成立。
3. 阈值被写成二元判据，但 LP 本来就允许部分使用珍奇。
4. 遗漏了“矿物利用每级 +4% 黑雾残骸产出”。
5. 有两处“验证”其实是循环论证或同义反复。

没有致命（critical）级错误。

## B. 问题清单（按严重度）

### 主要（major）

**M1. §0.3 / §5.3：“不加上限 z 就无界”这一说法不对，而且与报告自己的硬上限自相矛盾。**
- 每个白糖要 1 个反物质，反物质来自临界光子（2 光子 → 2 反物质 + 2 氢）。规划器每白糖确实要 critical-photon 1.0（增产后 0.8）。
- 所以 z ≤ 光子产率 +（黑雾反物质掉落，Lv21+），光子产率又受戴森球功率约束。这条上限与 UPS 无关，§0.3 和 §5.3 末段也把它列为由种子决定的硬上限。
- 同一节先说“z 无界”，再说“硬上限有三类”，前后矛盾。
- “L→∞”这个前提也不合理。L 是状态量，不是自由变量：到达 L 级要累计 2000·(L−6)(L−5) 个白糖，稳态模型里 L 只能是给定参数。
- **修改：**
  - 改写为：给定 L 时问题良定，z 受光子（戴森球）、气巨和油泉产率（随 L 放大）以及黑雾掉落约束；只是这个上限远高于 CPU 实际能承受的规模，所以实用的答案必须加建筑或 UPS 上限。
  - 删掉“z 也会无界”。
  - 可以补一个量级锚点：笑笑的两万糖要光子 324 GW、全厂 474 GW，约合 16 MW·min/白糖（光子部分）。
  - 另外给出两种良定写法：(i) 时间窗 T 内累计白糖最大；(ii) 给定 L，max z，同时加可持续约束（见 M2）。

**M2. §4.1“足以支撑无限研究、此后储量不会耗尽”只在白糖 100% 投入矿物利用、并且永远持续研究时成立。**
- 采矿速度随等级增长（每级 +10%）**不会**破坏结论：每开采 1 个矿石消耗的储量只由 0.94^L 决定，与速度无关。报告应写明这一点，因为题目直接问到了。
- 白糖分作他用时结论会变：
  - 如果有比例 φ 的白糖用于其他无限科技或别的用途，L 的增长会变慢，累计消耗变为 a_r·S(L)/(1−φ)。级数仍然收敛，判据改为 a_r·S(L)/(1−φ) ≤ B_r。
  - 如果某一时刻停止矿物利用研究（φ=1），每单位时间的消耗固定为 0.94^L>0，任何有限储量都终将耗尽。唯一的例外是 BWIKI 说的“390 级消耗为 0”。到达 L390 共需 2000·385·386≈2.97 亿白糖。
- 规划所用的工厂产量 z（§5.3）与这条判据有冲突。§5.3 的约束 2 写成 a_k(x)·S(L)/z_scale ≤ …，没有说明白糖的去向，量纲也说不清（z_scale 未定义）。
- **修改：**
  - §4.1 加上 φ 修正和“停止研究就失效”的说明。
  - §5.3 约束 2 改为 a_k(x)·S(L)/(1−φ) ≤ B_k − K_k，并删掉 z_scale。

**M3. 阈值被写成“二元放开”，但 LP 本来就允许部分使用；而且磁石 L≈98 用的是最费磁石的配方。**
- §4.3 阈值测试里，每种矿都设了上限 B_r/S(L)。在 L=6 时磁石上限是 0.18M/815k≈0.22 个/白糖，也就是说**从一开始就可以少量用磁石**，不必“等到 L98 才放开”。报告把 L98 写成唯一结论，误导了“何时用”这个问题。
- L98 基于情形 A（10 个/白糖，无增产），是最坏情况。笑笑的配方是 3.28 个/白糖：转写 [25:20] 的“328”是 1825k/556.879k=3.277。用这个值复算：
  - B=142k 时，第一个满足 a·S≤B 的是 S(81)=43 286，对应 141.9k ≤ 142k。按 S(L) 的定义，这正是“完成 80 级后开始用”，**与笑笑的 L80 完全一致**。这是比“3716k 对得上”强得多的验证。
  - 本种子 B=0.182M、a=3.28 时，阈值为 L=77。
- 更好的写法是：每级 n 允许不同的配方组合 x_n，约束为 Σ_n C(n)·0.94^(n−1)·a_r(x_n) ≤ B_r。它仍然是线性的。单一配方 a_r·S(L) 只是这个约束的一个可行子集，并不是最优。
- **修改：** §4.3 改成三层：
  1. 完全放开用的阈值：情形 A 为 L98；笑笑的配方为 L77（本种子）或 L80（笑笑档）。
  2. 早期可用的配额：每白糖 ≤ B_r/S(L)。
  3. 分级配方的 LP 写法（放到 §5.2）。

**M4. 遗漏了“矿物利用每级 +4% 黑雾残骸产出”；§5.4 对黑雾的框架也太窄。**
- BWIKI 矿物利用页每级都写着“+4% 残骸产出倍率”，黑雾掉落页写着“矿物利用科技可提升黑雾残骸掉率”，Saros readme 和 dsp-wiki 也都这样写。L85 时倍率为 1+0.04·85=4.4。
- 所以 d_{b,i} 应写成 d_{b,i}(lv, L)，与 L 线性相关。这直接影响 §5.4 的“(a) 阈值下降”和“(b) z 上限”两条结论。
- 黑雾不只掉原矿和专属物品。它还掉大量中间品：Lv9 处理器、Lv12 碳纳米管、Lv15 粒子容器和卡西米尔晶体、Lv21 反物质、量子芯片、引力透镜。笑笑说的“阴间三样”（粒子容器、处理器、碳纳米管）都能直接掉落，比“磁石变可再生”影响更大。
- 黑雾掉落的反物质还能绕开 M1 的光子上限。
- 情形 G“df-* 近乎免费，结果与 F 相同”只说明专属物品不在白糖链上，**不能**说明黑雾对白糖链没有影响。报告现在的写法容易被误读。
- **修改：** §3 黑雾行和 §5.4 都加入 (1+0.04L) 因子，补充中间品掉落，并写明情形 G 测试的范围。

**M5. 两处“验证”是循环论证或同义反复；成本规律可以直接升级为已核实。**
- §3 和 §10 说成本规律 4000·(n−5) 被“S 值与 815448 吻合间接支持”。这是循环论证：S 本来就是用这条规律算出来的，笑笑也用同一条规律，两者吻合只证明算术相同。
- 实际上 dsp-wiki 正文写明了 4000·(Level−5) 和 3.6M·(Level−5) 哈希，笑笑也直接口述了这条规律。改成已核实，并引用 dsp-wiki。
- §0.2 和 §4.1 说“他算的铁需求 3716k 也对得上”。3716k 就是 815448×4.5568，属于同义反复，不是独立核对。应删掉，或换成 M3 里的磁石 L80 复现。
- 815 449 这个结果社区早有人算过（2021 年 Reddit 帖、dsp-wiki 讨论页）。§0.2 称它为“本报告的核心推导”有夸大之嫌，应注明这是已知结论，本报告的贡献是把它接入 LP。

### 次要（minor）

- **m1 等级 L 的含义差一级。** 求和从 n=L 开始、系数为 0.94^(n−1)，所以 S(L) 表示“已完成 L−1 级、开始研究第 L 级”。笑笑的“跑到80级之后”对应 S(81)。§4.1 的“从等级 L 起”和 §4.3 的“L≈98”应写成“完成 97 级后（S(98)）”，表头也加一句定义。
- **m2 轨道采集器表格其实与 10% 线性吻合。** 报告说“不完全吻合，页面自身未解释”，这是误读：表格是净产量 = 毛产×(1+0.1L) − 固定自耗。
  - 气巨列：由 L0 和 L2 两点解出毛产 43 515、自耗 19 305，预测 L5 为 45 967（表中 46 019），L10 为 67 725（表中 67 728）。
  - 冰巨列误差在 2% 以内。
  - 净产是 L 的仿射函数，不是“线性式”（§5.1）。改写这一行即可。
- **m3 §2.3 气巨单位。** `gases` 是**行星**的基础气体速率（DoubleUTH planet.rs:531，已含 0.1 倍档的 ×0.8），不是“每台采集器的基础产率”。单台毛产 = 8×(1+0.1L)×该值，再按 30 MW 扣自耗。照现在的写法容易差 8 倍。
- **m4 抽水站。** 数据文件里基础值是 50/min，加上矿物利用速度加成：60 = 50×1.2。删掉这条存疑，§5.1 的海洋速率写成 50·(1+0.1L)/min。
- **m5 黄棒措辞。**
  - “核心素（黄棒）”是错的：黄棒是奇异湮灭燃料棒。
  - 按 dsp.json，每根黄棒的配方是反物质燃料棒 8、核心素 1、框架材料 1、奇异物质 2，不是“核心素、单极磁石等”。磁石只经粒子容器的替代配方间接进入。
  - 1 根/min = 1.2 GW 是精确值；笑笑说的是“≈1 GW”。所以 300 根/min ≈ 360 GW，不是 300 GW。
- **m6 §2.1 稀有档的系数。** 除了乘倍率，0.1 倍档还会把 resource_coef 取 ^0.8（当 >1 时）再 ×0.7，母星 ×2/3；距离因子在 32 ly 以外按迭代对数饱和（star.rs:187–199）。这会削弱“越远越多”的效果，建议补一句。
- **m7 “68k+74k”写成了事实。** hints 里标注了“两数含义存疑”；BV1wxikYXEHp 说的是“中子星一共 6万8”，BV1sQBtYxEsm 说的是合计 142k。改为“合计约 142k（分项存疑）”。
- **m8 §0.3 与 §5.3 列出的上限不一致。** §0.3 的瓶颈清单漏了油泉和气巨产率。在 0.1 倍档下：
  - 情形 A 每白糖要原油 15.5，两万糖需要 5.2k/s；
  - 而全星区初始只有 404.8/s，到 L80 也只有约 ×9。
  - 所以原油很可能是硬约束，除非改用可燃冰或石墨烯等路线。应补进 §0.3。
- **m9 原油下限偏悲观。** 衰减速度 ∝ (1+0.1L)·0.94^L。L80 时 0.1 倍档的半衰期约 5 h/0.064≈78 h，可见高等级下衰减很慢。长期按 0.1·(1+0.1L) 的下限建模偏保守。应注明这一点，并写入单台 7200/min 的上限。
- **m10 §5.1 按矿点数给开采上限。** 采矿机覆盖范围可以重叠，同一矿点可能被多台矿机同时开采（存疑，需要在游戏里核实）。如果成立，开采速率的上限来自矿机数量和占地，而不是 Nodes。建议标为存疑。
- **m11 研究站增产（存疑，需核实）。** 如果研究站用增产剂“额外产出”模式能多产 25% 哈希，每级所需白糖就是 4000(n−5)/1.25，S 会降 20%。建议在局限里提一句。
- **m12 缺少“到达阈值要多久”。** 累计白糖为 2000·(L−6)(L−5)：
  - 到 L81 需 1140 万，L86 需 1296 万，L98 需 1711 万；
  - 750 糖/min 时约 253–380 h，两万糖/min 时约 10–14 h。
  - “何时能用”需要这条换算，建议放进 §4.2。
- **m13 §4.3“L=6 就可行：不用固态珍奇”。** 阈值测试给所有珍奇都设了上限，只凭“可行”推不出“不用珍奇”。这个结论其实来自情形 E 的手算：铁 23.6M<127.8M，硅 22.8M<53.3M，铜 13.0M，钛 14.7M，石 3.3M。应明写这一步。另外注明测试里原油、水、硫酸没有设上限。
- **m14 815448 与 815449。** 精确值是 815448.91，两者只是截断和四舍五入的差别。“吻合到整数位”改为“截断后相同”。
- **m15 B_r 应取“剩余”储量。** §4.3 用的是开局总量，没有扣掉 L1–5 和早期建造的消耗，也没有考虑被黑雾占据、打不下来的星。对正在进行中的存档，B_r 应来自存档解析（w1w218 有存档解析器），而不是种子。建议在 §7 把存档列为在玩存档的主数据源。
- **m16 速度对比。** w1w218 称“精算 27 秒/种子”，DoubleUTH 是 0.7 s，botany233 是 1–3 s。差距约 40 倍，可能说明各实现的精确度不同（w1w218 强调 x86 浮点一致）。可以在 §2.4 作为“需要对拍”的又一个理由。
